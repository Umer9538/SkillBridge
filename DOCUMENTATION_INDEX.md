## 🆘 Getting Help

### If documentation doesn't solve your issue:

1. **Check Troubleshooting Sections**
   - [INSTALLATION_GUIDE.md](INSTALLATION_GUIDE.md#troubleshooting)
   - [QUICK_SETUP.md](QUICK_SETUP.md#common-issues)
   - [DEPLOYMENT_GUIDE.md](DEPLOYMENT_GUIDE.md#troubleshooting-production-issues)

2. **Check Logs**
   - Backend: `logs/backend.log`
   - Frontend: `logs/frontend.log`
   - Browser Console: Press F12

3. **Common Issues**
   - Port conflicts → See installation guides
   - Module not found → Reinstall dependencies
   - Permission denied → Check file permissions
   - Database errors → Check database setup

4. **Contact Support**
   - Create GitHub issue
   - Tag with appropriate label
   - Include error logs
