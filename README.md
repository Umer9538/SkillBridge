## 📖 What is SkillBridge?

SkillBridge is a comprehensive learning management platform that connects:
- 🎓 **Learners** - People who want to learn new skills
- 🏢 **Companies** - Businesses looking for talented individuals
- 👨‍🏫 **Supervisors** - Course creators and educators
- 🛡️ **Admins** - Platform administrators

---

## ✨ Key Features

### For Learners
- 📚 Browse and enroll in courses
- 🎯 Apply for real-world tasks from companies
- 📊 Track learning progress
- 🏆 Build professional portfolio

### For Companies
- 📝 Post tasks and projects
- 👥 Review learner applications
- 🎯 Hire skilled talent
- 📈 Manage task listings

### For Supervisors
- 🎓 Create and manage courses
- 📹 Add modules with videos, documents, and content
- 📊 Track learner progress
- ⭐ Evaluate submissions

### For Admins
- 👥 Manage all users
- 📊 View platform analytics
- 🔄 Impersonate users for testing
- 🛡️ Monitor platform activity

---

## 🛠️ Tech Stack

### Backend
- **Flask** 3.0.0 - Python web framework
- **SQLAlchemy** - ORM for database
- **SQLite** - Database (development)
- **Flask-JWT-Extended** - Authentication
- **Flask-Mail** - Email notifications
- **Flask-Bcrypt** - Password hashing

### Frontend
- **React** 18 - UI framework
- **Vite** - Build tool
- **Tailwind CSS** - Styling
- **React Router** v6 - Navigation
- **Axios** - HTTP client
- **Lucide React** - Icons
